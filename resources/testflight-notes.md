Thanks for testing VitaTrack! This is an early build — here's what to focus on:

WHAT'S NEW
First TestFlight build. Core features to try:
• Onboarding — set up a health profile and pick a goal
• Library — search for a supplement, add it to your list with a dosage/schedule, or scan a barcode
• Today — mark doses taken, check the monthly calendar view
• Interactions — add a medication and check for flagged combinations, dosage warnings, and FDA recalls
• Log — adherence history, and optional mood/energy tracking
• Profile — export/restore a backup, change your goal, clear data

PLEASE CHECK
• Reminder notifications — these need the app installed properly (not just launched) to fire reliably;
  let us know if a reminder time you set never notifies you
• Barcode scanning — camera behavior varies a lot by device; note your device model if it doesn't work
• Anything that looks visually broken on your specific screen size

KNOWN LIMITATIONS
• No account/cloud sync — data stays on this device only (use Profile → Download my data to back up)
• Reference data is for general guidance only, not medical advice — always confirm dosing and
  interactions with a pharmacist or doctor

Please report anything confusing, broken, or just off — including wording that doesn't read clearly.
Thank you!
